# Tbilisi — тестовое Firebird Tours (версия для GitHub Pages)

Это **кандидатская** редакционная страница, не официальный проект компании.
Основа — утверждённый макет v2 со вставкой панорамы и сбалансированной перелинковкой.

## Как опубликовать

1. Зарегистрируйтесь на https://github.com/.
2. Создайте публичный репозиторий **top-things-to-do-in-tbilisi** с веткой `main`.
3. Загрузите в корень все файлы этой папки, сохранив папки `.github/workflows/` и `assets/` (скрытая `.github` особенно важна).
4. Откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
5. Перейдите в **Actions**. Workflow `Build and publish Tbilisi page` стартует при загрузке файлов. Если не стартовал — выберите его и нажмите **Run workflow**.
6. Сценарий загружает оригинальные фотографии из Wikimedia Commons, создаёт оптимизированные версии WebP, собирает 84-секундный ролик на основе фотографий и электронного музыкального сопровождения и публикует страницу.
7. После успешной сборки адрес будет `https://ВАШ-ЛОГИН.github.io/top-things-to-do-in-tbilisi/`. Страница автоматически получает SEO canonical и Open Graph адрес.
8. Чтобы получить MP4 отдельно, откройте завершённый запуск в Actions и скачайте артефакт **tbilisi-video-84s**.

## Важно

- Видео — **фото-видеогид**, то есть реальные фотографии с плавным движением, **не** съёмка туристических видеоклипов. Визуальный стиль ролика можно улучшить и заменить на съёмочный фильм позже.
- Видео в тестовой странице встроено напрямую через HTML5 `<video>`, и его можно смотреть, не покидая статью. YouTube для прохождения требования задания не обязателен. Если нужно строго через YouTube — скачайте созданный MP4, разместите на YouTube и замените `<video>` на выданный YouTube iframe.
- Для YouTube выбирайте **Unlisted** (по ссылке), проверьте настройку **Allow embedding**. Не публикуйте страницу до проверки проигрывания видео.
- **Сборка ещё не протестирована на GitHub**, она может потребовать корректировок в зависимости от доступности Wikimedia Commons и GitHub Actions. Если workflow красный, не сдавайте страницу: пришлите журнал ошибок.
- Ранее файл `index.html` намеренно имел `noindex,nofollow` для предпросмотра; здесь заменено на `index,follow`.
- Логотип пока текстовый, поскольку официальный графический файл не получен. Для тестового не выдавайте страницу за официальный сайт Firebird Tours.
- Права на фотографии принадлежат авторам; атрибуция присутствует в статье и MEDIA_CREDITS.md. Фотографии с лицензиями ShareAlike нужно распространять согласно соответствующей лицензии. При формировании файла WebP выполнено масштабирование, а на сайте — отображение с возможной обрезкой.
- Источники и лицензии нужно в последний раз перепроверить перед передачей задания.

## Состав проекта

`index.html` — фиксированный макет; `article.md` — текст; `build.py` — автоматизация медиа, SEO и видео; `MEDIA_MANIFEST.json`/`MEDIA_CREDITS.md` — источники; `assets/tbilisi-original-theme.m4a` — авторская инструментальная мелодия; `.github/workflows/publish.yml` — публикация в GitHub Pages.

**Не загружайте ZIP целиком как один файл в репозиторий.** Распакуйте и загрузите его содержимое, включая скрытую папку `.github`.
